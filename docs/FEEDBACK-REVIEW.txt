Structured details
The SDK sends JSON text plus logfire.json_schema over OTLP. Logfire retains the decoded object or array in records.attributes.
Example query: SELECT attributes->'diagnostic.details'->'observations' FROM records WHERE span_name = 'development.diagnostic.summary'.
Caller frames are separate call_path.frames records. Diagnostic intervals describe measured windows, not exact stall boundaries.
